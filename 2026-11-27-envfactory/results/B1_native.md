## Protocol

- 3 OpenRouter flash models × 32 samples per pack, temperature 1.0, fixed seed.
- Prompt contains **only** the vulnerable file, the pack's own observed/expected PoC block, and a
  strict `diff` envelope. No `injection-spec.md`, `manifest.json`, `replay.md` or `variants/` text;
  `bon/native_prompts.py` enforces this with an explicit marker check.
- **Tier-1** = the pack's PoC main scenario (finite fixtures) + the targeted upstream unit module
  where it runs cleanly in this environment.
- **Tier-2** = the pack's held-out `variants/` triggers, which never appear in the prompt.
- A reply with no parseable diff, a diff that does not apply, or a tree that cannot build is
  **`untested`** — never a pass and never a kill.

## Adjudication appendix — every T1+ ∧ T2− completion

36 refutations. Refuted by: `pack/variants/aud-polyglot/run.sh` ×36.

36/36 variant outputs state that a token was issued for an assertion whose **effective**
audience is `https://attacker.example`, while the authorization server only accepts
`https://as.example.com/token` and `https://as.example.com`.

**Author's adjudication (evidence above; reviewer may disagree): REAL FLAW, not a spec quirk.** Each of
these repairs makes the *validated* view duplicate-free but leaves the audience check reading the raw
(last-wins) claims, so an assertion can be validated as addressed to the AS and still be honoured when
its effective audience is attacker-controlled. That is the same duplicate-member confusion class as the
shipped scope flaw, on a member the patch did not canonicalise. The 4 non-refuted repairs either reject
duplicate member names outright or canonicalise before every claim read.
